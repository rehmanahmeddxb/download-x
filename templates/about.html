YT Downloader X Pro

A self-hosted YouTube download manager built with Flask + yt-dlp, styled after commercial download managers. Runs locally in your browser — your downloads never leave your device.

Version 0.1.0 · Open Source · MIT-style license

Features
  • Fetch single videos, playlists, and channels
  • Full format list per video (resolution, codec, bitrate, size)
  • Parallel queue with pause / resume / cancel / retry / reorder
  • Automatic resume of partial downloads (yt-dlp continued download)
  • Dashboard statistics, history with CSV export
  • Dark neon UI, AJAX live updates, no WebSocket dependency
Tech Stack
  • Backend: Flask, Flask-SQLAlchemy, APScheduler, waitress
  • Engine: yt-dlp (latest), ffmpeg (optional, for merging)
  • Frontend: Bootstrap 5, Chart.js, SweetAlert2, Font Awesome
  • Packaging: Buildozer / python-for-android (APK)
