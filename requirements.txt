# Pinned so desktop runs and the APK build install identical versions.
# (Unpinned deps are a classic source of "worked yesterday, crashes today"
# APKs when a new major release slips in.) The same pins are mirrored in
# buildozer.spec, which ALSO needs every transitive pure-Python dep listed
# explicitly -- p4a cannot auto-resolve Android-incompatible wheels, so an
# unlisted dep (e.g. SQLAlchemy for flask-sqlalchemy) would silently be
# missing from the APK and crash the app on launch. Bump yt-dlp
# periodically -- YouTube changes break old versions regularly.
